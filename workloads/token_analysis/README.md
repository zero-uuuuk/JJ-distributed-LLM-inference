# Token Analysis

ShareGPT Chat과 MS MARCO RAG workload의 `prompt_tokens` 분포를 확인을 위한 파일들입니다.

| File | Description |
|---|---|
| [`prompt_token_distribution.png`](prompt_token_distribution.png) | Chat-only와 RAG-only의 요청별 prompt token 분포를 비교합니다. |
| [`chat_turn_prompt_tokens.png`](chat_turn_prompt_tokens.png) | Chat workload에서 turn이 증가할수록 prompt token이 누적되는 양상을 보여줍니다. |
| [`total_prompt_tokens.png`](total_prompt_tokens.png) | Chat-only와 RAG-only의 총 prompt token 합계를 비교합니다. |
| [`prompt_token_summary.json`](prompt_token_summary.json) | 위 분석에 사용한 입력 파일, 모델명, 통계 요약을 담습니다. |
